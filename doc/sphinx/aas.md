# Asset Administration Shell

- Two “kinds” of assets:
  - type asset (`Type`)
  - instance asset (`Instance`)

- Many different providers of AAS software
  - [BaSyx](https://basyx.org)
    - [Open source](https://github.com/eclipse-basyx)
    - AAS Environment:
      - AAS Discovery
      - AAS Registry
      - Submodel Registry
      - AAS Repository
      - Submodel Repository
      - Concept Description Repository
